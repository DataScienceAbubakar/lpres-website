Section 01

Project Overview

1.1 What is the L-PRES Website?

The Kwara State Livestock Productivity and Resilience Support (L-PRES) website is the official public-facing web platform for the Kwara State L-PRES Project — a World Bank-supported agricultural development initiative covering all 16 Local Government Areas of Kwara State, Nigeria.

The website serves two audiences simultaneously:

  • Public visitors — citizens, journalists, development partners who browse news, project sites, gallery and contact information.
  • Administrators — project staff who log in to publish news articles, manage the media gallery, and update project portfolio entries.

1.3 High-Level Architecture

The system has two distinct runtime environments:

Frontend (Browser)
  • React SPA served by Netlify CDN
  • React Router — client-side routing
  • AuthContext — JWT token state
  • Axios — HTTP requests to API
  • TipTap — rich text editor
  • Leaflet — interactive map
  • CSS Custom Properties — theming
⇄
Backend (FastAPI Server)
  • FastAPI + Uvicorn
  • 4 Routers: admin, news, gallery, projects
  • SQLAlchemy ORM → SQLite DB
  • JWT middleware for protected routes
  • Static file serving for uploads
  • bcrypt password hashing
Important Note — Two Modes

In local development, the React app talks directly to http://localhost:8000 (the real FastAPI server). On Netlify (live preview), there is no Python server — instead, three Netlify Functions (JavaScript) serve static JSON that mirrors the FastAPI response format exactly. The frontend code is identical in both cases.

Section 03

Backend Deep Dive (FastAPI)

3.1 How the Backend Starts

The backend is a single Python application in the backend/ folder. To run it:

cd backend
source venv/bin/activate      # activate Python virtual environment
uvicorn main:app --reload     # start the dev server on http://localhost:8000

When main.py is executed, FastAPI does these things in order:

1. Create the uploads folder
os.makedirs("uploads", exist_ok=True) — ensures the upload directory exists before any request arrives.
2. Create FastAPI app instance
Sets title, version. Adds CORS middleware allowing requests from any localhost port.
3. Create database tables
models.Base.metadata.create_all(bind=engine) reads all SQLAlchemy models and creates any missing tables.
4. Run migrations
run_migrations() checks if the images column exists in the projects table. If not, it runs ALTER TABLE to add it.
5. Include routers
Attaches admin, news, gallery, and projects routers — each prefixed with /api/<name>.
6. Seed default admin
Creates username admin / password lpres@admin2024 if no admin exists yet.
7. Seed sample data
Inserts 5 sample projects and 3 gallery items if the tables are empty. Skips if data already exists.

3.2 Database Layer

database.py wires up SQLAlchemy:

SQLALCHEMY_DATABASE_URL = "sqlite:///./lpres_website.db"

engine = create_engine(SQLALCHEMY_DATABASE_URL,
    connect_args={"check_same_thread": False})  # SQLite needs this for FastAPI
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
Base = declarative_base()  # All models inherit from this

def get_db():              # FastAPI dependency — yields a DB session per request
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
Junior Developer Tip

get_db() is a dependency. In any router function that needs the database, you write db: Session = Depends(get_db) as a parameter. FastAPI automatically calls get_db(), gives you the session, and closes it when the request is done — you never have to manage it manually.

3.3 Data Models (models.py)

Four database tables are defined as Python classes:

Admin
  • id — primary key
  • username — unique login name
  • email — unique email
  • hashed_password — bcrypt hash
  • is_active — boolean flag
  • created_at — auto timestamp
NewsArticle
  • title, body (HTML)
  • featured_image — file URL
  • images — JSON list of URLs
  • slug — unique URL-friendly ID
  • template — layout number (1–3)
  • is_published, category
GalleryItem
  • file_url — photo or video path
  • thumbnail_url — for video posters
  • media_type — "photo" or "video"
  • category, sort_order
  • is_published
Project
  • name, lga, cluster
  • description, status
  • cover_image — main photo URL
  • images — JSON list (gallery)
  • highlights — JSON list of strings
  • sort_order, is_published
JSON Columns

Columns like images and highlights use Column(JSON). SQLAlchemy stores them as JSON text in SQLite and automatically parses them back into Python lists. Never pass a JSON string to these columns — always pass a Python list directly, or SQLAlchemy will double-encode it.

3.4 Pydantic Schemas (schemas.py)

Pydantic schemas define the shape of data going into and out of the API. They are separate from the models because the database structure and the API contract are not always identical (e.g., passwords are stored hashed but never returned in responses).

SchemaUsed for
AdminCreate / AdminLoginRegistration and login request bodies
TokenLogin response — contains access_token
NewsArticleCreate / Update / OutCreate, update request bodies and response shape
GalleryItemOutWhat the gallery API returns
ProjectOutWhat the projects API returns

Every Out schema includes class Config: from_attributes = True — this tells Pydantic to read data from SQLAlchemy model attributes (not a dict).

3.5 Authentication System (auth.py)

The system uses JWT (JSON Web Tokens) for stateless authentication. Here is the full flow:

Admin submits username + password
Frontend POSTs to /api/admin/login as application/x-www-form-urlencoded (OAuth2 standard form).
Backend verifies password
passlib + bcrypt compares the plain password to the stored hash. If wrong, returns HTTP 401.
Backend creates JWT
python-jose signs a token with {"sub": username, "exp": now + 24h} using ALGORITHM = "HS256".
Frontend stores JWT in localStorage
The Axios interceptor in client.js automatically attaches it as Authorization: Bearer <token> on every request.
Protected endpoints verify the token
get_current_admin dependency decodes the JWT, looks up the admin in DB, and either returns the admin object or raises HTTP 401.
Security Note

The SECRET_KEY in auth.py must be changed before going to production on a real server. The current value is a placeholder. Use a randomly generated 64-character string.

3.6 API Routers

Each router is a separate file. FastAPI uses Python decorators to define endpoints:

@router.get("/", response_model=List[schemas.ProjectOut])
def list_projects(skip: int = 0, limit: int = 50, db: Session = Depends(get_db)):
    # FastAPI automatically converts the return value using ProjectOut schema
    return db.query(models.Project).filter(models.Project.is_published == True).all()

Public vs Admin Endpoints

Every router has two sets of endpoints. Public endpoints (no auth) return only published records. Admin endpoints require the get_current_admin dependency and return all records:

3.7 File Upload Pattern

All three routers (news, gallery, projects) use the same upload pattern:

async def _save_image(file: UploadFile) -> str:
    # 1. Validate MIME type against whitelist
    if file.content_type not in ALLOWED_IMAGE:
        raise HTTPException(400, "Unsupported type")

    # 2. Read entire file into memory and check size
    content = await file.read()
    if len(content) > MAX_IMAGE_SIZE:
        raise HTTPException(400, "File too large")

    # 3. Generate a UUID filename to prevent collisions and path traversal
    ext = file.filename.rsplit(".", 1)[-1].lower()
    filename = f"{uuid.uuid4().hex}.{ext}"

    # 4. Write to disk asynchronously (doesn't block the server)
    async with aiofiles.open(os.path.join(UPLOAD_DIR, filename), "wb") as f:
        await f.write(content)

    # 5. Return a URL path the frontend can use to fetch the file
    return f"/api/projects/uploads/{filename}"

Files are served back via a static endpoint in each router:

@router.get("/uploads/{filename}")
def serve_upload(filename: str):
    path = os.path.join(UPLOAD_DIR, filename)
    if not os.path.exists(path):
        raise HTTPException(404, "File not found")
    return FileResponse(path)   # FastAPI streams the file to the browser

3.8 Multi-Image Project Gallery

Projects have a cover_image (one main photo) and images (a list for the gallery carousel). On update, the admin UI sends two extra fields:

  • keep_images — JSON string listing existing image URLs to retain (those not listed are deleted from disk)
  • images — new file uploads to append to the gallery
# Reconcile: delete dropped images, keep retained ones
if keep_images is not None:
    keep_list = json.loads(keep_images)
    for url in (p.images or []):
        if url not in keep_list:
            _delete_file(url)   # physically removes from disk
    p.images = keep_list

# Append new uploads
if images:
    new_urls = [await _save_image(img) for img in images if img.filename]
    p.images = list(p.images or []) + new_urls

Route Protection

AdminRoute is a wrapper that checks authentication before rendering admin pages:

function AdminRoute({ children }) {
  const { isAuthenticated, loading } = useAuth();
  if (loading) return <div style={{ minHeight: '100vh' }} />;  // show blank while checking
  return isAuthenticated ? children : <Navigate to="/admin/login" replace />;
}

Scroll Animator

A lightweight IntersectionObserver-based animation system. No external library needed:

function ScrollAnimator() {
  const { pathname } = useLocation();
  useEffect(() => {
    const observer = new IntersectionObserver(
      (entries) => entries.forEach(e => {
        if (e.isIntersecting) {
          e.target.classList.add('in-view');  // triggers CSS transition
          observer.unobserve(e.target);       // animate only once
        }
      }),
      { threshold: 0.12, rootMargin: '0px 0px -30px 0px' }
    );
    const timer = setTimeout(() => {
      // re-scan for new [data-animate] elements after route renders
      document.querySelectorAll('[data-animate]:not(.in-view)')
        .forEach(el => observer.observe(el));
    }, 80);
    return () => { clearTimeout(timer); observer.disconnect(); };
  }, [pathname]);
  return null;  // renders nothing visible
}

To animate any element, add data-animate to it. Use data-delay="2" through "6" to stagger siblings. The CSS in index.css handles the rest.

4.2 Context Providers

AuthContext (context/AuthContext.jsx)

Manages the JWT token lifecycle and exposes a useAuth() hook:

// In any component:
const { admin, isAuthenticated, login, logout } = useAuth();

// login() calls the API, stores the token, then fetches /api/admin/me
// logout() clears localStorage and resets admin to null

On first render, if a token exists in localStorage, the context calls /api/admin/me to verify it is still valid before setting isAuthenticated = true.

ThemeContext (context/ThemeContext.jsx)

Controls dark/light mode by toggling a data-theme attribute on <html>. CSS custom properties in index.css respond to this attribute.

4.3 API Client Layer (api/client.js)

A single Axios instance is shared across all components. It has two interceptors:

Request Interceptor

Before every request: reads lpres_admin_token from localStorage and appends it as Authorization: Bearer ... header. If no token, nothing is added (public routes work without it).

Response Interceptor

On every response: if status is 401 (Unauthorized), clears the token from localStorage and redirects to /admin/login. Handles expired tokens automatically.

API calls are grouped by resource:

export const newsAPI = {
  list:   (skip, limit) => api.get(`/api/news/?skip=${skip}&limit=${limit}`),
  get:    (slug)        => api.get(`/api/news/${slug}`),
  create: (formData)    => api.post('/api/news/admin/create', formData,
                            { headers: { 'Content-Type': 'multipart/form-data' } }),
  // ...
};

export const projectsAPI = { /* same pattern */ };

Always use these named API objects in your components, never construct raw axios.get() calls. This gives you one place to change URLs or headers if the backend changes.

4.4 The OnTheGround Component — Live Data Fetching

This is the best example of how a section component fetches and displays real backend data:

export default function OnTheGround() {
  const [apiProjects, setApiProjects] = useState([]);

  useEffect(() => {
    fetch(`${API_BASE}/api/projects/?limit=20`)
      .then(r => r.json())
      .then(data => {
        if (Array.isArray(data) && data.length > 0) setApiProjects(data);
        // If empty or error, apiProjects stays [] and FALLBACK data is used
      })
      .catch(() => {});   // silently ignore network errors
  }, []);

  const displayProjects = apiProjects.length > 0 ? apiProjects : FALLBACK;
  // ... render using displayProjects
}

Section 05

How Frontend and Backend Sync

5.1 The Request Lifecycle (end-to-end)

Here is what happens when a visitor loads the homepage and the Projects section fetches data:

Browser loads the React app
Netlify CDN serves frontend/dist/index.html and the JS bundle. React hydrates the page.
OnTheGround component mounts
useEffect fires after the first render. It calls fetch(`${API_BASE}/api/projects/?limit=20`).
Request hits Netlify redirect
Because VITE_API_URL="", API_BASE is an empty string, so the URL is /api/projects/ — a relative URL. Netlify's netlify.toml redirect rule intercepts it.
Netlify Function handles the request
netlify/functions/projects.js returns the hardcoded JSON array of 5 projects. In local development, this step is replaced by the real FastAPI server at localhost:8000.
React updates state
setApiProjects(data) triggers a re-render. The project cards display with the real data.
Image URLs are resolved
mediaUrl(url) checks if the URL starts with http. If it's a relative path like /uploads/seed_hero.jpg, it is prefixed with API_BASE to form the full URL.

5.2 The Critical ?? vs || Distinction

This is one of the most important technical decisions in the codebase. Every non-news file uses:

const API_BASE = import.meta.env.VITE_API_URL ?? 'http://localhost:8000';
OperatorFalls back when value is...Behaviour with VITE_API_URL=""
?? (nullish coalescing) null or undefined only ✅ Uses "" → relative URLs → Netlify redirects work
|| (logical OR) Any falsy value: null, undefined, "", 0, false ❌ Falls back to localhost:8000 → broken on Netlify
Do Not Change

NewsSection.jsx and all news template files intentionally still use ||. They are not to be modified. The netlify/functions/news.js compensates by returning absolute Unsplash URLs for images, so the concatenation produces a valid URL regardless.

5.5 Media URL Resolution

Every component that displays uploaded images uses this helper function:

const API_BASE = import.meta.env.VITE_API_URL ?? 'http://localhost:8000';

function mediaUrl(url) {
  if (!url) return null;
  // If url already starts with http, use as-is (absolute URL from Netlify function)
  // If url is a path like /api/projects/uploads/abc.jpg, prepend API_BASE
  return url.startsWith('http') ? url : `${API_BASE}${url}`;
}

This handles both environments transparently:

Section 06

Netlify Deployment

6.1 Why Netlify for the Preview?

The full system (FastAPI + SQLite) requires a Python server that cannot run on Netlify's static CDN. For the client preview site, Netlify was chosen because:

  • Free hosting with global CDN (sub-100ms load times)
  • Automatic HTTPS
  • Netlify Functions allow simple JavaScript serverless functions to mimic the FastAPI responses
  • One-command deployments: npx netlify deploy --prod

6.2 netlify.toml Explained Line by Line

[build]
  command = "cd frontend && npm run build"  # Vite builds the React app
  publish = "frontend/dist"                  # Serve from this output folder

[functions]
  directory = "netlify/functions"            # JS serverless functions location

[build.environment]
  VITE_API_URL = ""                          # Empty string → relative API URLs

# Each [[redirects]] block maps a URL pattern to a function
[[redirects]]
  from   = "/api/projects"          # Match this URL path
  to     = "/.netlify/functions/projects"  # Forward to this function
  status = 200                      # 200 = proxy (not a real redirect)

[[redirects]]
  from   = "/api/projects/*"        # Also match /api/projects/1, /api/projects/anything
  to     = "/.netlify/functions/projects"
  status = 200

# ... same for /api/gallery/* and /api/news/*

[[redirects]]
  from   = "/*"                     # MUST be last — SPA catch-all
  to     = "/index.html"            # All unmatched URLs → React app
  status = 200
Redirect Order Matters

API redirects must come before the SPA catch-all (/*). If the catch-all were first, every /api/projects request would return index.html instead of the JSON data, and the whole site would break.

6.3 Netlify Serverless Functions

Each function in netlify/functions/ is a JavaScript file that exports a handler function. It receives the HTTP request and returns a response object: 

// netlify/functions/projects.js  (simplified)
exports.handler = async (event) => {
  const headers = {
    "Content-Type": "application/json",
    "Access-Control-Allow-Origin": "*",
  };

  // Check if a specific ID was requested (e.g., /api/projects/2)
  const path = event.path.replace(/^\/api\/projects\/?/, "");
  const id = path ? parseInt(path, 10) : null;

  if (id) {
    const project = PROJECTS.find(p => p.id === id);
    if (!project) return { statusCode: 404, headers, body: JSON.stringify({ detail: "Not found" }) };
    return { statusCode: 200, headers, body: JSON.stringify(project) };
  }

  // Return all projects
  return { statusCode: 200, headers, body: JSON.stringify(PROJECTS) };
};

The PROJECTS array at the top of the file mirrors the exact shape of schemas.ProjectOut from the FastAPI backend. This is critical — if the shapes don't match, the frontend breaks.

6.4 Static Assets on Netlify

Uploaded photos stored in backend/uploads/ during local development are not accessible on Netlify (there is no Python server). Instead, copies were placed in frontend/public/uploads/: 

# Files placed in frontend/public/uploads/:
seed_hero.jpg     # used by Netlify functions as cover images
seed_spc.png      # coordinator photo
seed_video.mp4    # sample video in gallery

Vite copies everything in public/ to dist/ at build time, so these are served as static files by Netlify CDN at /uploads/filename.jpg.

Section 08

Key Design Decisions

8.1 Why ?? (nullish coalescing) instead of || ?

The Netlify build sets VITE_API_URL="" (an empty string). Empty strings are falsy in JavaScript. Using || would fall back to 'http://localhost:8000' even in production. Using ?? only falls back for null or undefined, so "" is used as-is, making all API calls relative — which Netlify then routes to the Functions.

8.2 Why Netlify Functions Instead of a Real Server?

The client wanted a shareable preview URL immediately, without setting up server infrastructure. Netlify Functions are zero-configuration JavaScript that run on AWS Lambda under the hood. They serve static JSON matching the FastAPI schema shape. When a real production server is deployed, only VITE_API_URL needs updating — the frontend code changes nothing.

8.3 Multi-image Pattern: keep_images + images

When editing a project's gallery, the admin can remove existing photos (by not listing them in keep_images) and add new ones (via file upload). Sending only the list to keep (not a list to delete) means the backend makes one pass through existing images, compares to the keep list, and physically deletes orphaned files from disk. No separate "delete image" API endpoint is needed.

8.4 NewsSection — The Frozen Component

NewsSection.jsx and all news display templates are intentionally never modified. They use || for API_BASE (not ??) and concatenate API_BASE with image paths. The Netlify news function compensates by returning absolute Unsplash image URLs, which the startsWith('http') check in the templates recognises as complete URLs.

8.5 SQLite for Storage

SQLite is a file-based database (one .db file) with no server process required. This is a good fit for a single-server deployment with low concurrent write load. If the project scales or needs multiple server instances, migrating to PostgreSQL with SQLAlchemy requires only changing the SQLALCHEMY_DATABASE_URL in database.py — all model and router code stays the same.

10.1 Glossary

FastAPIPython web framework that auto-generates API docs, validates data with Pydantic, and is very fast due to async support.

JWTJSON Web Token. A signed string containing the admin's username and expiry. The server never stores sessions — it validates the signature on every request.

CORSCross-Origin Resource Sharing. Browser security rule that blocks requests from localhost:5173 to localhost:8000 unless the backend explicitly allows it.
Context (React)A way to share state across many components without passing props through every layer. AuthContext makes login state accessible anywhere in the app.
useEffectReact hook that runs code after the component renders. Used for data fetching, subscriptions, and DOM interactions.

HMRHot Module Replacement. Vite's ability to update changed modules in the browser instantly during development without a page refresh.
Router (FastAPI)An APIRouter groups related endpoints. Each router has a prefix (e.g., /api/news) so endpoint paths don't need to repeat it.
Dependency InjectionFastAPI pattern: Depends(get_db) means "call get_db() and pass its result as the db parameter". The framework handles calling it.

10.2 Top Tips for Junior Developers

Tip 1 — Read the Swagger Docs First

With the backend running, visit http://localhost:8000/docs. You can try every API endpoint interactively without writing any code. This is the fastest way to understand what data each endpoint expects and returns.

Tip 2 — One File Per Concern

The project strictly separates concerns: database config in database.py, table definitions in models.py, response shapes in schemas.py, auth logic in auth.py, and API routes in routers/. When you need to add a field, you will typically need to update models, schemas, AND the router.

Tip 3 — Never Hardcode API URLs in Components

All API calls go through api/client.js. If you need a new endpoint, add a method to the appropriate API object (newsAPI, galleryAPI, etc.). Never write axios.get('http://localhost:8000/...') directly in a component.

Tip 4 — Adding a New Section to the Homepage

Create MySection.jsx and MySection.css in components/sections/, then import and add it to pages/Home.jsx. Add data-animate to the section header element. No other configuration needed — the ScrollAnimator picks it up automatically.

Tip 5 — Test Both Environments

After making changes, always test locally (with the FastAPI backend running) AND on Netlify. Some bugs only appear in one environment — particularly anything involving API URLs or file paths.

Critical — Never Modify NewsSection.jsx

frontend/src/components/sections/NewsSection.jsx and all files in the news templates folder must NOT be edited. They use || for API_BASE by design, and the Netlify news function is tuned to compensate. Modifying these files will break the news display in unpredictable ways.

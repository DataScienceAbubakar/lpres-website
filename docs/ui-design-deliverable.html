09 · Motion

Animation Principles

Motion is purposeful and minimal. All animations serve to guide attention, confirm interactions, or reveal content progressively. No decorative animation exists solely for aesthetics.

Scroll Reveal — Slide Up
cubic-bezier(0.22, 1, 0.36, 1) · 0.6s
Used on: section headers, cards, content blocks. Triggered once when element enters viewport.
Hero Entrance — Fade Up
cubic-bezier(0.22, 1, 0.36, 1) · 0.55–0.65s
Used on: badge → title → subtitle → CTAs. Staggered by 0.12s each using animation-delay.
Stagger Delay System
data-delay="1" → +0.08s per step
Apply data-delay="1" through "6" to sibling elements for cascading reveals without JavaScript delay logic.
Background Slowzoom
ease-in-out alternate · 22s infinite
Hero background image gently scales 100% → 108% over 22 seconds. Creates depth without distraction.

Interaction Transitions

Hover: Cards
transform: translateY(-2px)
transition: 0.2s ease
Subtle lift + border highlight on card hover
Hover: Buttons
opacity: 0.88
transition: 0.15s ease
Slight opacity dim. No scale or colour shift.
Reduced Motion
prefers-reduced-motion:
animation: none
All animations and transitions disabled for users who request it via OS settings.
